# Publish with GitHub Pages

1. Add the portfolio files to the `anushafernandes/anushafernandes` repository.
2. Commit and push the files to the branch selected in the repository's GitHub Pages settings.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the branch containing the portfolio files and the `/ (root)` folder.
6. Save the settings and wait for GitHub Pages to publish the website.

No GitHub Actions workflow is required for branch-based deployment.

For a PDF résumé, export the DOCX file to PDF, place it in `resume/`, and update the résumé links in `index.html`.
