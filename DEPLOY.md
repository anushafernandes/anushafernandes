# Publish with GitHub Pages

1. Create a new GitHub repository, for example `anusha-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `resume/` folder.
3. In GitHub: Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
7. Replace the GitHub placeholder link in `index.html` with your actual GitHub profile URL.

For a PDF resume, export your DOCX resume to PDF and place it at:
`resume/Anusha_Fernandes_Sept_2026.pdf`
